## 자바(Java)란?

- **정적 타입 언어**: 변수의 타입을 컴파일 시점에 결정한다. (Python과 가장 크게 다른 점)
- **객체지향 언어**: 모든 코드는 클래스(class) 안에 존재한다.
- **컴파일 후 실행되는 언어**: `.java` 소스 코드를 컴파일하면 `.class`(바이트코드)가 생성되고,
  JVM(Java Virtual Machine)이 이 바이트코드를 해석해서 실행한다.

```
HelloWorld.java  --(javac 컴파일)-->  HelloWorld.class  --(java 실행, JVM)-->  프로그램 실행
```

## Python과의 비교

| Python | Java |
|---|---|
| 인터프리터 언어 (한 줄씩 즉시 실행) | 컴파일 언어 (컴파일 후 JVM에서 실행) |
| 동적 타입 (`x = 10`) | 정적 타입 (`int x = 10;`) |
| 들여쓰기로 블록 구분 | 중괄호 `{}`로 블록 구분 |
| 문장 끝에 세미콜론 불필요 | 문장 끝에 세미콜론(`;`) 필수 |
| 파일 자체가 실행 단위 | 클래스 단위로 코드를 구성, `main` 메서드가 진입점 |

## 개발 환경 준비

1. **JDK(Java Development Kit) 설치** — 이 저장소는 JDK 17을 기준으로 한다. (`build.gradle`의 `sourceCompatibility` 참고)
2. **IDE** — IntelliJ IDEA 사용을 권장한다.
3. **프로젝트 구조 확인**
   - `src/main/java/org/example/` 아래에 실습 코드가 패키지별로 정리되어 있다.
   - 각 챕터 폴더(`chapter_00_2_hello_world/` 등)의 `README.md`에는 학습 내용과 설명이,
     `src/main/java/org/example/chapter00_2/` 등에는 실제 실습 코드가 들어 있다.

## 학습 방법 안내

1. 각 섹션의 `README.md`를 먼저 읽고 핵심 개념을 이해한다.
2. `src` 아래의 실습 코드를 직접 실행해 보고, 값을 바꿔가며 결과가 어떻게 달라지는지 확인한다.
3. 코드를 그대로 따라 치는 것보다, **직접 값을 바꾸거나 새 예제를 만들어 보는 것**이 학습에 훨씬 효과적이다.
4. 0-8(훈련) 섹션의 문제는 답을 보기 전에 반드시 스스로 먼저 풀어본다.

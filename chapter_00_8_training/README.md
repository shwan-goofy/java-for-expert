# Chapter 0-8: 훈련

## 학습 목표

- 0-2 ~ 0-7에서 배운 변수, 연산자, 조건문, 반복문, 형변환을 종합적으로 활용한다
- 문제를 스스로 분석하고 코드로 구현하는 연습을 한다
- 각 문제를 **답을 보기 전에 직접 먼저 풀어본다**

## 문제 목록

아래 문제들은 순서대로 난이도가 올라간다. `TrainingMain.java`의 각 메서드(`problem1` ~ `problem5`)에 풀이가 들어 있다.
먼저 스스로 풀어본 뒤 풀이와 비교해 보자.

### 문제 1. FizzBuzz

1부터 30까지 숫자를 출력하되,
- 3의 배수이면 숫자 대신 `"Fizz"`
- 5의 배수이면 숫자 대신 `"Buzz"`
- 3과 5의 배수이면 `"FizzBuzz"`
를 출력하라.

> 힌트: 조건 검사 순서가 중요하다. `3의 배수` 검사와 `5의 배수` 검사보다 **`15의 배수` 검사를 먼저** 해야 한다.

### 문제 2. 별 찍기 (직각 삼각형)

다음과 같은 모양을 5줄로 출력하라.

```
*
**
***
****
*****
```

> 힌트: 중첩 `for`문을 사용한다. 바깥 반복은 줄(행), 안쪽 반복은 그 줄에 찍을 별의 개수를 담당한다.

### 문제 3. 최댓값과 최솟값 찾기

정수 배열이 주어졌을 때, 배열 안에서 가장 큰 값과 가장 작은 값을 찾아 출력하라.

```java
int[] numbers = {45, 22, 89, 7, 63, 90, 11};
```

> 힌트: 배열의 첫 번째 값을 임시 최댓값/최솟값으로 놓고, 반복문을 돌며 비교해서 갱신한다.

### 문제 4. 구구단 표 (2차원 배열 활용)

2단부터 9단까지 구구단 결과를 2차원 배열에 저장한 뒤(`result[dan-2][j-1]`에 `dan * j` 저장),
저장된 배열을 순회하며 출력하라.

> 힌트: 2차원 배열 크기는 `[8][9]`(2단~9단, 1~9)로 잡는다.

### 문제 5. 성적 처리기 (메서드로 추출)

학생 5명의 점수 배열이 주어질 때, 다음을 모두 메서드로 분리하여 구현하라.
- `calculateAverage(int[] scores)`: 평균 점수를 `double`로 반환
- `getGrade(double average)`: 평균에 따라 등급(`"A"`, `"B"`, `"C"`, `"F"`)을 반환
- 위 두 메서드를 조합해 최종 평균과 등급을 출력

```java
int[] scores = {88, 95, 72, 60, 99};
```

> 힌트: 총합을 구할 때 정수 나눗셈 오버플로/버림에 주의한다 (0-4, 0-7 참고).

## 실습 예제

`TrainingMain.java`에서 문제 1~5의 풀이를 확인할 수 있다. 각 문제는 `problem1()` ~ `problem5()` 메서드로 분리되어 있고,
`main`에서 순서대로 호출한다.

# Chapter 0-11: 강의 소개와 자료 (자바 중급 과정)

## 학습 목표

- 지금까지의 자바 입문 과정([0-1 ~ 0-10](../chapter_00_10_methods/))과 이 중급 과정의 관계를 이해한다
- 중급 과정에서 다루는 전체 구성을 미리 확인한다
- `Object` 클래스를 시작으로 자바가 "모든 것이 객체"인 이유를 이해할 준비를 한다

## 지금까지 배운 것 (자바 입문, chapter 0-1 ~ 0-10)

- 변수, 연산자, 조건문, 반복문, 스코프/형변환, 배열, 메서드
- **절차적인 코드 작성**에 필요한 최소한의 문법

이 지식만으로는 "변수와 흐름 제어"는 다룰 수 있지만, 자바가 객체지향 언어로서 제공하는
강력한 기능(상속, 다형성, 불변성, 예외 계층 등)은 아직 다루지 않았다.

## 이 중급 과정에서 다루는 내용

| 섹션 | 주제 | 핵심 내용 |
|---|---|---|
| 0-12 | Object 클래스 | 모든 클래스의 최상위 부모, `equals`/`hashCode`/`toString` |
| 0-13 | 불변 객체 | 불변 객체를 만드는 이유와 설계 방법 |
| 0-14 | String 클래스 | 문자열 풀, 불변성, `StringBuilder` |
| 0-15 | 래퍼, Class 클래스 | 기본형의 객체 버전, 오토박싱, 리플렉션의 시작점 |
| 0-16 | 열거형 - ENUM | 상수 집합을 안전하게 다루는 방법, enum 심화 |
| 0-17 | 날짜와 시간 | `java.time` 패키지로 날짜/시간을 다루는 표준 방법 |
| 0-18 | 중첩 클래스, 내부 클래스 1 | static 중첩 클래스, 인스턴스 내부 클래스 |
| 0-19 | 중첩 클래스, 내부 클래스 2 | 지역 클래스, 익명 클래스와 실전 활용 |
| 0-20 | 예외 처리 1 - 이론 | 예외 계층 구조, 체크/언체크 예외, `try-catch-finally` |
| 0-21 | 예외 처리 2 - 실습 | 커스텀 예외, 예외 전환(wrapping), 실전 패턴 |

이 과정을 마치면 자바의 클래스 라이브러리가 어떻게 설계되어 있는지("왜 `equals`를 재정의해야
하는가", "왜 `String`은 불변인가", "왜 `Optional` 같은 것이 필요한가"의 배경)를 이해하게 되고,
이후 이 저장소의 `chapter_01` ~ `chapter_06`(제네릭, 클래스 설계, 상속, SOLID, 중첩 클래스 심화)를
더 깊이 있게 학습할 수 있는 토대가 마련된다.

## 학습 방법 안내

- 이 과정의 예제 코드는 `src/main/java/org/example/chapter00_12` ~ `chapter00_21`에 있다.
- `Object`, `String` 같은 이름은 자바 표준 라이브러리 클래스와 겹치므로, 실습 코드에서는
  `MyObjectExample`, `MyStringExample`처럼 구분되는 이름을 사용한다. 실제 코드에서 헷갈리지 않도록
  각 챕터의 README에서 왜 그렇게 이름을 지었는지 설명한다.
